# Additional file 4 - Analysis Scripts

Seven portable analysis scripts aligned to the frozen 14-system reader-facing package.

The scripts operate on Additional files 2 and 3. The patient-cluster bootstrap script
is provided for reproducibility but is not run during construction of this submission
package; the supplied source-data summary remains the frozen 20,000-replicate result.
