# Public release checklist

- [ ] Upstream code licences and notices have been reviewed.
- [ ] `CITATION.cff` contains GitHub URL and ORCID.
- [ ] `.zenodo.json` contains ORCID and correct affiliation.
- [ ] No personal absolute paths remain.
- [ ] No raw MRI/DICOM/XML/PNG or model checkpoints are tracked.
- [ ] No credentials, tokens, passwords, or private keys are tracked.
- [ ] Fixed fold file has 468 patients.
- [ ] Sanitised ROI manifest has 2,978 rows.
- [ ] Each primary OOF prediction file has 2,978 rows.
- [ ] PowerShell and Python syntax checks pass.
- [ ] SHA256SUMS has been regenerated after all edits.
- [ ] GitHub repository is public and default branch is `main`.
- [ ] Zenodo GitHub integration is enabled before creating the release.
- [ ] GitHub release tag is `v1.0.0`.
- [ ] Zenodo version DOI is copied back to README and the manuscript.
